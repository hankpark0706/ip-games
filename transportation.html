Route the Convoy · a.k.a. the Hitchcock transportation problem

Transportation Problem

Each depot holds a fixed supply; each front-line unit needs a fixed amount. Supply equals demand (a balanced problem). Every route has a shipping cost per unit. Decide how much to ship on each route so every depot empties and every unit is fully supplied — at the lowest total cost. Use −/+ in each cell, then Submit. Hit New Problem for a fresh board.
